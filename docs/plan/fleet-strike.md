# 함대 격침 — 클래식과 변형

원문은 `docs/spec/DIRECTIVES.md` D-035이다. **게임을 두 종으로 나눈다** — 표준 규칙 그대로의
**클래식**(2인)과, 프리셋으로 화력과 배를 고르는 **변형**(개인전 n인)이다. 카탈로그에 각각 등록하고
같은 리듀서를 공유하되 규칙은 분기한다.

계획서 §3은 함대 격침을 **멀티 최초 도입 지점**으로 두었다 — 턴당 좌표 하나만 오가서 통신 배관이
가장 작기 때문이다. 그 성질은 변형에서도 유지한다(좌표와 사격 타입만 오간다).

---

## 1. 클래식 — 먼저 나온다

표준 함대 격침이다. 2인, 10×10, 배 5척(5·4·3·3·2칸), 턴당 한 발. 여기서 **좌석별 화면 가리기**
(누구에게 무엇을 보여줄지)와 멀티 배관을 만든다.

**변형이 나중에 공짜가 되도록 클래식 단계에서 심어 둘 것 넷** — 지금 넣는 비용은 사실상 0이고,
안 넣으면 변형에서 리듀서를 다시 써야 한다.

1. 상태를 `참가자[] = {함대, 피격기록}` **배열**로 둔다. 2인을 `n=2`의 특수한 경우로 짠다
2. 사격을 `{쏜사람, 맞은사람, 칸, 사격타입}`으로 기록한다. 2인이라도 「맞은사람」과 「사격타입」을 남긴다
3. 화면 가리기를 **관전자를 포함한 좌석별**로 만든다
4. 승패를 「상대 전멸」이 아니라 **「생존자가 하나」**로 판정한다

## 2. 변형 — 판과 함대

- **12×12** 판이다(클래식은 10×10).
- **기본 함대는 6척 21칸** — 2칸 1척 · 3칸 2척 · 4칸 2척 · 5칸 1척.
- 시작할 때 **공격 프리셋과 특수 배를 고르고** 들어간다.
- **프리셋 3개를 띄우고 그중 하나를 고른다.** 프리셋은 배 구성과 화력이 미리 짝지어진 묶음이다.
- [도출] 3개는 **매 판 무작위로 뽑는다.** 늘 같은 3개면 고르는 행위에 의미가 없다.

## 3. 사격 타입

| 이름 | 사양 |
|---|---|
| 연속 사격 | **3턴 동안 총 3·4·5·6회**를 나눠 쓴다. 턴당 최소 1회, 최대 2회 |
| 일제 사격 | **모든 적에게 같은 좌표로** 쏜다. 1회 또는 2회 |
| 예광탄 | 턴당 1회로 줄어드는 대신, 기본 사격이 **적중 칸의 인접 4칸을 밝힌다** |
| 고폭탄 | **인접 4칸까지 함께 폭격**한다(피해가 들어간다) |
| 조명탄 | **피해를 주지 않는 대신 적중 칸을 밝힌다.** 턴당 1·2·3회 |

- [도출] **「밝힌다」는 그 칸에 배가 있는지 없는지만, 쏜 사람에게만 알려주는 것**이다. 배의 종류나
  방향은 알려주지 않고 다른 참가자에게도 공개하지 않는다 — 전원 공개면 정보를 얻는 의미가 없다.
- [도출] 연속 사격의 「3턴 동안 총 n회」는 **자원 배분**이다. 한 턴에 몰아 쓰면 다음 턴이 비고,
  턴당 하한이 1회라 아무 턴도 완전히 비지는 않는다.

## 4. 배 타입

| 이름 | 사양 |
|---|---|
| 추가장갑 | 배의 **중앙 1칸이 2회 맞아야** 부서진다 |
| 잠수함 | **4칸 고정.** 모든 부위가 부서지기 전까지 격침 사실을 알리지 않는다. 다만 **잠수함이 마지막 1척이 되면 위치가 공개**된다 |
| 항공모함 | **살아 있는 동안 추가 화력**을 준다. 대신 **한 대만 맞아도 배치가 알려진다** |
| 유리대포 | **1×1 크기.** 상대에게 2턴마다 고폭탄 1회를 주는 대신, 자신은 **매 턴 추가 예광탄**을 얻는다 |
| 클래식 조합 | 표준 함대의 칸수·개수를 조합한 프리셋들 |

- [도출] 잠수함의 「마지막 1척」은 **그 사람의 남은 배가 잠수함 하나뿐일 때**다. 숨을 곳이 없어지면
  숨기는 의미가 사라지고, 이 규칙이 없으면 판이 끝나지 않는다.
- [도출] 항공모함의 「배치가 알려진다」는 **맞힌 사람에게만** 알려주는 것으로 본다(밝히기와 같은 규율).

## 5. 미결 — 사용자 확인 대기

이 넷은 원문에서 도출할 수 없어 구현 전에 사용자가 정해야 한다.

1. **턴이 동시인가 순차인가.** 「3턴 동안」·「턴당」은 라운드를 전제한다. 개인전 n인에서 순차면
   자기 차례가 n턴에 한 번 오고, 동시 제출이면 라운드 시간이 인원수와 무관해진다.
2. **전멸한 사람을 어떻게 하는가.** 최후 1인까지 가면 먼저 죽은 사람이 오래 구경한다.
3. **유리대포가 「상대에게 주는」 고폭탄의 대상.** 모든 상대인가, 한 명인가, 그 사람은 그것을
   누구에게든 쓸 수 있는가.
4. **항공모함의 「추가 화력」이 구체적으로 무엇인가.** 사격 1회 추가인지, 고폭탄 부여인지.
