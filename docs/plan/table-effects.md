# 판 위 연출 — 동전 · 주사위 · 덱

**무엇에 대한 문서인가**: 게임 진행을 돕는 연출 세 가지(동전 던지기, 주사위 굴리기, 덱 섞기)의
사양. 게임 규칙은 이 문서에 없다.

**원문**: `docs/spec/DIRECTIVES.md` D-010. 아래 내용과 원문이 어긋나면 원문이 이긴다.
**전역 제약**: `docs/PLAN.md` §5 색 · §6 화면 규칙 · §11 구조 예산.

각 항목은 **[원문]**(사용자가 지정) 또는 **[도출]**(그 지시에서 계획이 끌어낸 것)로 표시한다.

---

## 1. 공통

- [원문] **게임 목록에 연출 테스트 페이지를 둔다.** 지금은 이 연출을 쓰는 게임이 없으므로 여기서
  확인한다.
- [원문] 동전과 주사위는 **「던지기!」 버튼으로 던지는 것과 자동으로 던져지는 것 두 가지**를 만든다.
- [원문] 시점은 **탑뷰**다. 화면 가운데에서 **화면을 뚫고 나오는 방향으로** 던져져 바닥에 떨어진다.
- [원문] 동전과 주사위는 **한 번쯤 가볍게 땅에 튕긴다.**
- [원문] **3D나 유사 3D가 힘들면 대체안을 써도 된다** — 동전은 림버스식(빙글빙글 돌다가 «핑!» 하며
  멈춤), 주사위는 마리오파티식(눈이 상자 열리듯 스크롤되다가 «틱!» 하고 한 번에 멈춤).
- [도출] 대체안을 골랐으면 **무엇을 왜 골랐는지 `REVIEW:`에 남긴다.** 두 방식을 모두 만들지 않는다 —
  하나만 고르고, 나중에 바꾸고 싶으면 그때 바꾼다.
- [도출] **연출은 결과를 만들지 않는다.** 무엇이 나왔는지는 부르는 쪽이 정해서 넘기고 연출은 그것을
  재생할 뿐이다. 원격 대국에서 쓸 때는 대표 클라이언트가 결과를 정해 실어 보내고 각자 자기 화면에서
  재생한다 — `room-lobby.md` §8.2 룰렛과 같은 구조이며, 각자 굴리면 서로 다른 것을 본다.
- [도출] 흑백만 쓴다. 플레이어 구분 색(§5)은 이 연출에 들어가지 않는다.

## 2. 동전 던지기

- [원문] **최대 12개**를 동시에 던질 수 있다.
- [원문] 앞면은 **흰 바탕에 검은 글자 `H`**, 뒷면은 **검은 바탕에 흰 글자 `T`**.
- [도출] 개수는 테스트 페이지에서 고른다. 1개일 때와 12개일 때 모두 화면 안에 들어와야 한다(§6 화면
  잘림 금지가 상위 규칙).

## 3. 주사위 굴리기

- [원문] **6면체만** 우선 만든다. **흰 주사위에 검은 눈.**
- [원문] **최대 6개**를 동시에 굴릴 수 있다.
- [원문] 3D로 만들면 **주사위끼리 어느 정도 부딪힌다.**
- [도출] 대체안(마리오파티식)을 골랐으면 부딪힘은 해당 사항이 없다.

## 4. 덱 섞기

- [원문] **덱은 하나만** 있으면 된다.
- [원문] 순서는 이렇다 — 반투명 회색 레이어를 **화면 전체에** 깐다 → 시야 한가운데에 카드 덱을
  스폰한다 → 덱이 섞인다 → 다시 하나의 덱 모양으로 돌아온다 → **인터레이스 방식으로 좌우로 갈라져
  사라진다** → 레이어를 끈다.
- [원문] 아래에 자막으로 **「OO덱이 섞이고 있습니다」**를 함께 띄운다.
- [원문] 이것은 **애니메이션일 뿐**이다. 나중에 카드를 쓰는 게임에서 덱이 섞였음을 알리는 용도다.
- [도출] 덱 이름(`OO`)은 부르는 쪽이 넘긴다. 테스트 페이지에서는 아무 이름이나 넣어 확인한다.

## 6. 비네트 — 화면 가장자리 점멸 (D-012)

- [원문] 화면 **가장자리만 아주 가볍게 검정 그래디언트**로 점멸시킨다. 판을 가리지 않는 세기여야
  한다 — 어두워지는 것이 아니라 가장자리가 스치듯 밀려드는 정도다.
- [원문] 부르는 쪽이 **점멸 주기를 바꿀 수 있다.** 투표는 5초 남았을 때 1초 주기로 시작해 3초부터
  250ms로 줄인다(`room-lobby.md` §8.4).
- [도출] **공용 도구다.** 남은 시간을 알리는 것 말고도 위험·마지막 턴·경고 같은 데 쓸 수 있으므로,
  "무엇을 알리는가"는 부르는 쪽이 정하고 이 도구는 세기와 주기만 받는다.
- [도출] 색은 검정 하나다(§5 플레이어 색을 쓰지 않는다). 화면 잘림 규칙(`PLAN.md` §6)을 넘지 않게
  화면 안쪽으로만 그린다.
- [도출] 「모션 줄이기」를 켠 기기에서는 점멸 대신 **고정된 옅은 가장자리**로 대체한다(`styles.css`가
  이미 `prefers-reduced-motion`을 다룬다).

## 7. 카운트다운 — 하단 숫자 (D-012)

- [원문] 남은 초를 **숫자로 화면 제일 하단에** 띄운다.
- [도출] **공용 도구다.** 부르는 쪽이 남은 시간과 표시 여부를 넘기고, 도구는 그리기만 한다.
  투표는 미투표자가 0명이라 1초로 고정된 경우 **비네트와 함께 끈다**(`room-lobby.md` §8.4).
- [도출] 하단은 대국 화면에서 「AI 생각중...」(`PLAN.md` §6.5-a)이 뜨는 자리와 같다. 두 가지가 동시에
  필요한 상황은 없다 — AI가 생각할 때는 사람이 투표하지 않는다.
